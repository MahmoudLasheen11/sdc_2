# FastAPI tutorial

From this directory, install the locked dependencies and start the in-class app:

```sh
uv sync --locked
uv run --locked uvicorn inclass_fastapi_app:app --reload
```

Open [the interactive API docs](http://127.0.0.1:8000/docs). Use Python 3.11 or
newer. See [the repository setup guide](../README.md) for notebook, assignment,
dev container, and test commands.
